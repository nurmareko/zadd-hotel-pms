# Mockup Reference Note

The files in this folder are historical design references from early ideation - not the current spec, implementation contract, or source of truth.

For current behavior, use the `*_mvp.md` specs in `docs/`, `prisma/schema.prisma`, and the implementation in `src/app/`. Some mockups describe concepts that were never built or have changed since the early design pass.

Example: `screens-permissions.jsx` shows a permission-matrix screen, journal/audit-log UI, and an `AUD` role label. Those do not match the current implementation: the accounting role is `ACC`, and no permission-matrix route exists.
